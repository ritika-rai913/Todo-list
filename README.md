# ✅ To-Do List

**Organize Your Tasks, Boost Your Productivity!**

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**. It allows users to add, manage, and remove tasks through an easy-to-use interface. This project helps users organize their daily activities and keep track of their tasks efficiently.

## ✨ Features

- ➕ **Add Tasks:** Easily add new tasks to your to-do list.
- 🗑️ **Delete Tasks:** Remove tasks that are no longer needed.
- 📝 **Manage Tasks:** Keep your daily activities organized.
- 🎨 **Simple Interface:** Enjoy a clean and user-friendly design.
- 📱 **Responsive Design:** Use the application on different screen sizes.

## 🛠️ Technologies Used

- **HTML** – Structures the web application.
- **CSS** – Styles the interface and layout.
- **JavaScript** – Adds interactive functionality and task management.
